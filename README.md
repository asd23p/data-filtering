# 授权店铺数据筛选

本工具只处理你有权访问并从平台或数据服务**手动/通过授权 API 导出**的 CSV 或 Excel 数据。它不访问抖音网页、不监听网络请求，也不包含浏览器自动化或反爬绕过功能。

## 安装

```powershell
python -m pip install -r requirements.txt
```

## 输入格式

输入文件必须包含以下列：

| 列名 | 说明 |
| --- | --- |
| 店铺名称 | 店铺名称 |
| 体验分 | 数值，例如 `4.35` |

以下列可选；若缺少，会填入默认值：

| 列名 | 默认值 |
| --- | --- |
| 主营类目 | 待查 |
| 带货达人/来源 | 授权数据源导入 |
| 店铺链接 | 空 |
| 跟进状态 | 待加微 |

CSV 请使用 UTF-8 或 UTF-8 BOM 编码。Excel 输入仅支持 `.xlsx`。

## 使用

```powershell
python filter_shops.py --input ".\授权平台导出.xlsx"
```

指定输入、输出路径和体验分区间：

```powershell
python filter_shops.py --input ".\授权平台导出.csv" --output ".\筛选结果.xlsx" --score-min 4.20 --score-max 4.50
```

结果按店铺名称去重。无符合条件的店铺时会导出只有表头的 Excel，不会伪造示例数据。

## API 接入

不同平台或数据服务的授权 API 在认证方式、字段和分页上各不相同。请先使用官方文档与已获授权的凭据导出符合上述列结构的数据，再交给本工具筛选；不要将登录凭据写入代码或提交到版本控制。如需直接接入某个 API，请提供其官方接口文档以及获准使用的认证方式。
